# 财务市区：五阶段十级精细化与氛围要求

定稿：2026-09-16，随一期完整规格获用户最终确认。**已确认方向**：当前建模仍偏素；各级都要更细、更有氛围，Lv.9–10 达到明显豪华和繁荣的程度，加入射灯、赛博全息广告、飞行广告。下表将此方向落实为建模与动效方案，具体布置由实现和审图验证，不表示模型已经制作。

本文件强化 [原十级建筑提案](city-progression-references.md)，保留五大发展阶段/十级结构。以已批准 v0.4 混合建筑为几何基础，保存原始版本；细化可通过独立附加部件及新变体完成。旧模型不再自动等于新等级的最终成品质量。

## 氛围如何服务成长

- 五阶段分别体现街角生活、邻里商业、区域中心、成熟繁荣、豪华未来都会。不同等级的建筑轮廓与氛围同时发展，不把区分等级的任务全部交给小装饰或亮度。
- 白天保留材料层次、广告载体/投影装置、公共空间和活动；夜晚加强暖窗、立面光、广告发光与射灯。不能只有晚上才能看出高级。
- 全息广告使用原创内容、投影装置及适当透明/发光表现；飞行广告有实际可移动的载体几何，例如无人机广告架或小型飞艇，不引入真实广告平台。
- 氛围是当前模型等级的视觉配置，不增加一套金融活跃度评分，也不改变财务、认证或历史业务规则。降级时恢复对应级别的建筑与氛围。
- 动态广告、飞行物和射灯遵守现有暂停/减少动态设置；灯光遵守昼夜与灯光开关。视觉播放不产生财务记录或真实航班事件。
- 运动采用独立视觉时钟；暂停后静态照明仍可保留，真实行程时间继续推进。飞行广告使用财务区内的独立路径，不复用航班调度，也不占用机场进离场通道。

## 空间、资源与验收

- 保留 60×44 m 财务地块、60 m 建筑上限和真实米制。飞行载体路径与地标、镜头、机场/高铁动画进行空间检查；不扩大金融区或改变其他区块。
- 保存旧繁荣几何作为独立原始状态；新细化部件/高等级变体不覆盖原始参考。最终等级映射在建模清单中明确，避免旧精确1/2/3可见区间使更高级消失。
- 每一级都做白天、夜晚、至少两个相反角度的检查。隐藏等级文字并把财务地块缩至约200 px时，相邻级别的建筑/整体构图仍可辨。
- Lv.9与Lv.10额外检查：近看有真实建筑构件与场景细节，总览有明显豪华繁荣轮廓，夜景的光束/广告/飞行物有层次且不遮挡交互入口。
- 活跃等级以外的动态效果应停止更新；检查切换、反复预览、升级和降级后的材质、发光、对象清理、帧率及内存。不要为效果数量让页面持续加载全部等级的重动态资源。
- 场景级灯光不能仅依赖建筑节点隐藏：灯具、广告、飞行物及其更新器应随当前显示级别统一启停，离开预览或降级后清理。全息广告使用专属材质；材质复制需保留发光与必要的 shader/uniform，不破坏已有车辆暖色舷窗。
- 优先复用几何和材质，限制同时投影阴影的移动灯光。记录实际渲染调用、三角形、帧率和资源占用，再确定动态效果预算；目前尚无新增效果的性能验证结果。
- 不承诺用截图、夜光贴片或后期滤镜代替要求的真实建筑/载体几何；也不要求所有光束都使用高成本真实体积光。具体渲染实现以多角度效果和性能验证为准。

图鉴的锁定/曾达成/当前状态单独由业务规则决定，不等同于这些静态模型文件是否存在或可以预览。
