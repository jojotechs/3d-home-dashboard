## 依赖与执行约定

- 18 票共 24 条直接依赖，已脚本检查无环、无重复传递边；H18 的传递依赖汇合此前所有票。当前唯一首片为 H01。
- H01 后记录与经营分支可并行；H02 后指定日期、每周任选、周/月累计可并行；H09 后南瓜、鸡和六位分组可并行；设施分支从 H08 开始。
- 每票从用户行为贯穿必要的云端、授权、UI、模型和验证。必要前置整理随首条消费该能力的切片完成，不单开空壳数据库/后端/前端票。
- 每票新增写路径当票完成权限、回执/重放、未知结果和并发检查；最后两票只做完整组合与发布回归，不替代前面的验收。
- 所有浏览器操作使用 **in-app browser**，不操作 Chrome。每个适用切片独立验证桌面/窄屏、真实云端确认与刷新；写入只用隔离测试家庭，不向真实家庭植入测试数据。
- H01 在线验证当前日记录、实际 30 秒与真实雏菊 0→1 格；三日成熟用受控时间的同一业务边界验证并标注。H05 必须在当天从真实周期目标达标走完成熟→收取。模拟时间不能成为生产后门，也不能冒充真实跨日验收。
- H01 从一块真实 GLB 建立模型契约，后续物种/设施随对应经营路径交付；原批准的基础建筑、农场边界、米制比例和七街区保持一致。
- 每个实际模型附阶段、局部坐标、交互锚点和多视角/净空检查；小人活动、日夜预览和模型加载从不执行业务交易。
- 每票已使用 `ready-for-agent`，正文 Blocked by 与 GitHub 原生阻塞关系一致；开工仍须读取实时 blocker 状态。发布前后父规格正文、标签及 OPEN 状态保持一致。
