# 习惯及农场经营属于本人，家庭公开只增加读取权

2026-10-20，用户确认习惯只由有账号的本人管理和记录，不做无账号习惯成员、代记或代管；逐习惯可选择私密或向当前同家庭成员公开完整记录，但管理员不自动获得私密访问权。农场成长、仓库、农场币和设施都属于本人，公开记录不贡献别人的农场、今日计数、推荐或中央住宅；这保留了家庭可见性，又避免私密行为通过共享模型或经济变化泄露，既有家庭成员及财务授权体系不因此删除或改义。

授权后的个人投影必须覆盖所有入口及场景；退出、换身份和失去家庭资格时清除旧投影并阻止迟到请求复原。公开转私密后，后续云端读取立即拒绝，已有分享视图在权限刷新时清空；公开不扩展到仓库、交易或整座个人农场。
