# 认证与访问权限属于应用入口

2026-09-17，用户指出 UI 职责也应像代码模块一样解耦。登录改由独立模态弹窗承载，账号身份与退出位于屏幕右上角；财务等业务面板只处理本模块事务。

地图、区域目录、今日事务/任务和推荐卡片经同一入口检查：未登录保留目标并提示登录，认证成功且权限允许后继续进入；没有权限则展示独立提示。每次进入读取当前云端权限，不能把隐藏入口当成服务端授权。`get_access_context` 只读取当前认证身份的家庭和模块权限，不读取财务金额。

当前生活与出行仍为本机演示，已加入家庭即可访问；财务另需既有 `finance_access`。这次调整没有创建逐模块权限管理界面，后续模块真实业务接入时仍需自己的服务端授权。登录、取消和退出在共享认证层串行处理，面板卸载不能让迟到响应覆盖另一身份。
