# 种养生产、商品目录和场景资产分别演进

2026-10-20，用户选择种植→收获→出售→购买的个人农场经营，并明确要求随时扩展品种。作物每轮消耗种子、动物长期持有、三格成长完成一轮、设施只改善外观；通过稳定品种/物品标识、少量生产策略和独立真实 GLB 资产目录组合，而不把六个地块编号、模型显隐节点或品种名称写成核心业务分支。

普通新品种增加定义、资产和验证即可复用打卡、生产、收取及交易；新机制才扩展策略。已有库存、动物、设施、轮次、成熟产物和成交回执保留原定义，改价或下架不能让它们失去含义。个人场景只投射授权后的已确认状态，街上行人和昼夜动画不结算交易；模型更新、切组和资源释放不能改变成长或库存。
