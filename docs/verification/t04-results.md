## 交付行为

- 沿用 T02 的 `save_finances` 公开事务：仅发送变动行、逐行版本检查、整笔原子提交、完整历史、原创建者及独立编辑者归属。本票不修改已上线迁移，不引入协作锁或自动合并保存。
- 同行冲突后保留全部输入，明确提示本次未保存。读取最新记录后，变动版本的冲突行标记“待核对”，展示云端名称、金额、最近修改者和北京时间。逐项选择“采用云端记录”或“保留我的修改”后才能再次保存；前者只替换该行，不丢弃其他草稿。再次读取不能跳过尚未完成的核对。
- 待移除记录同样展示最新归属、金额并要求确认；云端已移除的项目保留草稿用于查看，但必须放弃该项，不能复活已退役身份。输入恰好等于最新云端值时不提交无变动更新。
- 提交结果未知时保留原请求和输入，锁定编辑及读取按钮，先用同一个请求重试确认。明确版本冲突才退出未知状态、进入核对流程。
- 收到成功回执后不再重发补丁。回执可能对应较早提交，必须读取当前账本后才能继续编辑；如果此时读取失败，提示“本次提交已保存”，保留只读状态并提供重新读取，避免旧回执导致重复提交或覆盖后续编辑。
- 冲突提示自动进入视野并获得焦点；登录、权限、账号 UI 仍属于应用层。
