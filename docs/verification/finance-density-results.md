# Lv.8–10 密度与氛围优化

2026-09-29。用户指出高等级比 Lv.7 空、氛围不足；这是对已交付建模的视觉修订，不新增业务切片。固定起点 `234f062`。参考与取舍见 [设计记录](../planning/finance-density-atmosphere.md)。

## 真实建筑与氛围

查阅并在应用内浏览器观察 Anno 1800、Cities: Skylines、SimCity Cities of Tomorrow、Cloudpunk 的官方图像与说明。采用错落中层楼、连续街墙、纵向商业层次和局部冷暖广告，所有模型仍为原创程序化 Blender 几何。

Lv.8–10 均为九组主要建筑体量：原有双地标、中央建筑、六段带真实门窗/橱窗/店名的临街建筑。六段街墙混合石材竖柱、退台玻璃和铜顶酒店三种结构，逐级提高中层体量。保留贯通步行巷、临街步道、咖啡桌、屋顶花园及入口。

Lv.9 有地面与屋顶两组全息、折面塔冠轮廓灯、两架飞行广告；Lv.10 有四组全息、观景台和花冠灯环、协调光带、三架广告。暖窗、青绿/珊瑚/金色招牌材质独立，统一受夜间开关与街区生命周期控制。

- 新增密度检查先发现旧 Lv.8 比 Lv.7 稀疏，随后生成模型通过；彩色灯牌的保色、关灯、暂停及销毁测试先红后绿。
- `npm test`：80/80；typecheck、build、Sites4/4通过。主 Three bundle 大于500KB的既有构建提示仍存在。
- Standards：1项启发式问题，已修复；0待处理。Spec：1项P2，已修复；0待处理。两路分别发现同一处退台上层灯带悬空。现在建筑和灯带共用 `setback_profile()`，实际 GLB 复核上层带后移3m并缩到5.5m。最终塔冠补光与光源预算调整也通过两路复审。

## 帧率与部署

同一台机器、生产应用内浏览器、1625×954画布、22:00夜景、运行中的车辆/行人/广告。此为交互采样，不是跨设备性能保证。

| 场景 | 观察 FPS |
| --- | ---: |
| 未改动的Lv.7 | 55.1 |
| 增密后Lv.10，优化前正反面 | 26.6–29.4 |
| Lv.10，光源优化后正反面 | 42.4–44.7 |

发现增密后的实时光照成本过高后，将Lv.8–10统一为5盏局部点光和4盏立面投射灯（Lv.10原为9+6），保留发光窗、招牌、轮廓灯、全部建筑和广告几何。最新实际GLB重新通过密度、行人净空、广告扫掠、日夜多视角检查。Lv.10仍比Lv.7更重，这是已观察到的限制，不能宣称达到稳定60FPS。

实现提交`ec4d60a`、`8b04617`、`bd22f89`、`80d1120`已推送main。Vercel生产部署`6732341075`（代码`80d1120537f3a5a01bb92d680595cfe9da6a4780`）状态success，生产域名 https://3d-home-dashboard.vercel.app/ 实际载入5盏点光/4盏投射的新Lv.10资源。最终浏览器警告/错误日志为空。
