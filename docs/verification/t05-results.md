# T05 · 财务历史与趋势

2026-09-22；Issue #7；基线 `1eafa8d`。实时前置 #4 已关闭。

## 实现

财务面板使用“当前账本 / 历史与趋势”两个视图，切换保留当前草稿；从授权的 `get_finance_history` 读取完整云端历史。趋势按保存时间展示，金额、极值和明细使用整数分。空历史不生成点或示例。展开记录可看当时余额、负债、储蓄净额、操作人、北京时间及各项原创建者。

迁移 `202609220002_finance_history.sql` 在写入时保存操作人昵称，包含清空账本的更新；旧记录优先从当时快照补齐，否则使用现有成员昵称。历史已有名称、金额与创建者快照不改变。
