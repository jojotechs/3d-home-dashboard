# T06 · 当前十级、历史最高和下一目标

2026-09-22；Issue #8；开始前实时依赖 #4 已关闭。

## 实现

`growth.mjs` 是十级计算及场景投影的公共入口，整数分比较；当前等级取当前已保存净额，历史最高独立从有效历史计算，空历史没有虚构峰值。支持负数、直接跨级、立即降级和满级继续记录。下一门槛与差额精确到分。

授权 `get_finance_book` 一次数据库快照返回当前账及历史，供数值与峰值使用。未确认提交、草稿及演示 localStorage 不产生真实等级。只在成功确认并读到最新账后提示升级/降级。场景只接收当前身份获授权的投影；换账号或失去权限时隐藏。预览投影不改变当前值。十级新几何仍由后续建模票制作；本票保持基础模型，并在 UI 清楚标识。
