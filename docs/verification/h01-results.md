# H01：每日私密习惯与雏菊农场验收记录

2026-10-21。**数据库已部署，Web 生产部署验收待完成；H01 整票尚未标记完成。** 对应 [H01 / #20](https://github.com/jojotechs/3d-home-dashboard/issues/20) 和[父规格 #19](https://github.com/jojotechs/3d-home-dashboard/issues/19)。本文先记录已取得的本地、真实云端和 in-app browser 证据，生产部署版本及正式站验收稍后补充。

本片范围是本人私密的每日手动打卡、有限免费雏菊种子、明确播种、延迟成长、三格成熟、自动续种与逐习惯收取；场景显示当前选中的一个种养位。计量、其他周期、分享、归档、六位分组、出售及付费商店仍属后续票。使用方式见[H01 使用与维护](../habits-runbook.md)。

- 经用户授权，使用 Supabase 的 Resume 恢复原有免费项目；未更换项目或购买服务。
- 迁移 dry-run 只列出新增 `202610210001`，随后 push 成功。远端与本地的八份迁移版本一致，详见[迁移回读](h01/migrations.txt)。这证明数据库已应用，不代表 Web 已发布。

- 验收通过真实 Auth 和两个公开 RPC 进行，未用直接写私有表构造浏览器结果；私有 schema 访问被拒绝，也没有公开业务时钟覆盖入口。相关结果见[浏览器云端回读](h01/browser-cloud-readback.json)。

## 真实云端当前日验证

`npm run test:cloud:habits` 为 **1/1 通过，总耗时约 38.2 秒**，见[执行日志](h01/cloud.txt)和[结构化证据](h01/cloud-current-day.json)。目标账号及同家庭另一成员开始时各自习惯数均为零。

- 创建本人私密习惯、领取有限种子、明确播种；重复同一领种请求返回相同响应且只入库一次，同 ID 换数量被拒绝。
- 两个真实 HTTP 请求竞争同一天打卡，只一个成功，另一个收到已记录错误；成功请求重放返回原始完整响应。
- 保存时间为 `02:51:14.504617Z`，固定撤销截止为 `02:51:44.504617Z`；真实时间读回为 `02:51:46.521446Z`。读回时恰好一格已确认成长、零成熟成果，过期撤销被拒绝，重放不延长原期限。
- 另一次实际记录在窗口内撤销，之后没有发格。同家庭其他成员不能收取该人的成果，其他家庭及匿名身份被拒绝；旧日新请求过期。
- 本次实时链验证了 0→1 格，未把受控时间生成的三格成熟、FIFO 或历史记录描述成真实连续多日操作。

桌面使用 1280×720：从空状态创建习惯，领取两包种子并明确播种，库存减为一包；真实保存当日记录，实际经过 30 秒后场景成长由 0 到 1，再从云端读回。另一条习惯在撤销窗口尚余约 18 秒时撤销。关闭再打开面板后草稿保留，切换所选习惯会清除旧习惯的场景投影。

### 无财务权限与审批边界

为验收额外临时切换财务权限的操作被自动审批审查拒绝，**该操作未执行**。随后使用既有 `.env.t03-test` 中无财务授权的隔离测试账号，只读调用其本人农场入口，成功返回本人状态；没有变更该账号权限，也没有创建习惯、发格或增加库存。首次读取可按正常规则初始化空个人账户。

[回读证据](h01/browser-cloud-readback.json)记录 `financeGrantRequired=false`、`permissionsChanged=false`。因此可确认习惯访问不要求财务授权，不能据此声称本轮成功执行过财务授权切换。
