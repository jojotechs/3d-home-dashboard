# 全局账号入口与模块访问验收

2026-09-17，按用户对 T01 的 UI 反馈调整。审查基线：`a8334aa`。正式地址：[家庭小城](https://3d-home-dashboard.vercel.app/)。

## 行为与职责

- 登录是独立模态弹窗；右上角账号入口展示成员、家庭、邮箱及退出，小屏保留头像入口。
- 财务面板不再承载登录/退出。地图、九个地区目录、推荐卡片、今日事务与任务选择统一检查登录和权限。
- 未登录先登录，通过后继续原目标；无权限提示，不挂载被拒模块。取消清除目标，退出立刻清除业务面板和金额。
- 新 RPC `get_access_context` 已迁移至实际 Supabase 项目，只返回当前身份和授权，不含金额。家庭成员可用生活演示；财务另需财务权限，数据库原有读写授权继续生效。
- 登录取消会中止请求，并在 SDK 清理完成前阻止下一次登录。账号信息尚未读到时不误报“未加入家庭”，可重读。

## 验证

- 数据库测试先观察 `get_access_context` 不存在的失败，再实施迁移并通过：成员权限、未入家庭、匿名拒绝、财务撤权、权限响应不含金额。
- 本地完整测试 **42/42**，类型检查通过；Sites **4/4**，构建保留三个 Sites 产物。模型和 Sites 包装未修改。
- 真实只读云测试通过：`node --env-file=.env.local --env-file=.env.access-test --test tests/cloud/access.test.mjs`。隔离成员可用生活模块、不可读财务或历史；匿名不可读取权限上下文。
- in-app browser 九个地区目录均在匿名时弹出登录；另验证今日事务、推荐卡和地图入口。
- 独立测试管理员登录后自动恢复财务，读回既有 ¥3,456.78，账号不再出现在财务面板中；从右上角退出后财务区域移除。
- 无财务授权的隔离测试成员登录后被拒绝进入财务，提示联系管理员；中央住宅可正常进入。
- 登录 A 后立即取消，再登录 B，显示 B 身份；取消不打开原模块。重读账号信息可恢复正确成员与家庭。
- 检查桌面和 390×844 窄屏的实际弹窗与菜单截图：焦点进入邮箱，原页面为模态背景；菜单层级高于时钟；窄屏检查后已恢复默认视口。
- 正式家庭未用于写入或权限变更测试。`.env.access-test` 仅用于隔离成员，包含 TEST_EMAIL / TEST_PASSWORD / TEST_USER_ID / TEST_HOUSEHOLD_ID；本机忽略且权限 0600，不提交凭据。
