# H01 雏菊模型与场景公开边界验证

2026-10-21。这里记录真实 GLB、Blender 导入和场景资源生命周期证据；不是云端打卡或浏览器经营验收。当前日真实保存、实际 30 秒和浏览器刷新由 H01 集成证据独立记录。

## 交付与接入

- `public/models/habits/daisy.glb` 是 Blender 生成的米制真实几何，包含三种当前轮阶段、独立成熟花篮和六块中性标牌。
- 原 `family-city.glb`、农场静态建筑、七街区布局及现有生成源码未修改。旧 `dynamic_habits` 的 72 个增长根由城市接入层永久隐藏；原 `static_habits`、命中面和焦点/标签锚点保留。
- 静态旧品种名称与农场建筑合并在同一网格，新标牌覆盖旧字并显示位置编号，不拆掉已批准建筑。新资产位于农场局部坐标，当前选中习惯固定使用原第一地块 `(-14, 12)`；所有本人习惯可以通过面板轮换投射该位，六位分组是 H13 的范围。
- `FarmDistrict` 以 `district_habits` 为父对象。`setProjection({identity, habitId, planted, progress, ready})` 只消费授权后已确认投影；`progress` 是当前轮 0–2 格，`ready` 是旧成熟份数；无身份或无习惯时只保留中性标牌。可撤销的成长预览留在业务界面，不生成可收取场景资产。
- 一个资源包同时包含三个阶段，当前最多显示一个阶段和一个花篮。即使 `ready=9000` 也只显示一个篮子，不按份数实例化；切换习惯/身份读取最新投影，加载结束不恢复旧身份。`dispose()` 释放几何、材质及贴图并阻止迟到挂载或回调。
- `update()` 不推进业务时钟、成长或生产；模型接受现有城市照明，无新增行人活动、灯光配额或场景写操作。

## 复现命令

```sh
bash modeling/run-blender.sh modeling/build_habit_farm.py
bash modeling/run-blender.sh modeling/verify_habit_farm.py
bash modeling/run-blender.sh modeling/render_habit_farm.py --quick
node --test tests/habit-farm-scene.test.mjs
```

使用已安装的 Blender 4.5.7 LTS。首次受沙箱限制的 Blender 进程在脚本执行前退出，随后通过获准的沙箱外 Blender 命令完成生成、导入验证和渲染；没有下载运行时。

## 场景公开接口检查

`tests/habit-farm-scene.test.mjs` 直接通过公开 `FarmDistrict` 接口以及真实 Three 场景检查交付 GLB；不模拟内部场景模块。网络交付边界被延迟或返回错误，以构造实际模型的迟到与重试。

4/4 通过：

1. 0→1→2、旧待收与新轮分离、9,000 份仍为单篮、清空身份只留中性基础。
2. 加载中换身份只挂载最新投影，释放时每份几何/材质只释放一次。
3. 下载期间关闭不挂载、不保留资源、不向已关闭场景发布迟到回调。
4. 加载失败后可重试；整天视觉时间和暂停参数不改变生产；缺种子仅保留成熟篮。

先运行首次公开边界测试得到缺模块失败，再完成实现变绿。随后关闭期间回调测试先得到 `1 !== 0`，补充关闭保护后四项全部通过。精确云端、30 秒和真实浏览器证据仍由对应集成验收负责。
