## v0.8 多机位与双向出发

机场现在同时停靠三架蓝、青、珊瑚色尾翼的客机，高铁站同时停靠两列双驾驶室高铁。真实行程根据自身出发时间稳定选择机位/站台与东、西出发方向，刷新后保持一致；每次点击“预览出发”会轮换组合，飞机共有六种、高铁共有四种。正在出发时，其余车辆保持候班，随后新班次回到原机位或站台。

- 客舱使用独立的暖色发光材质，修复动画复制材质时丢失夜间窗光的问题。停靠、出发和补班期间均随昼夜渐亮渐暗，也服从“入夜亮灯”开关。
- 机场扩展机坪和跑道南侧海岸，安排倒推、弧形转向、独立滑行道与两端回转区。客机仍保持 25.722 m 长、25.801 m 翼展；三架飞机之间留有真实尺度的活动空间。
- 高铁两端都有驾驶室，换向时交换白色前灯与红色尾灯；不需要原地旋转整列车。每列长 52.6 m、宽约 2.9 m，始终沿自己的轨道进出山体隧道。
- 新版飞机完整出发及补班周期为 84 秒，高铁为 39 秒。相近真实行程仍按顺序展示，同一时刻同方式的行程仍合并为一班。
- 原七个生活分区及行人/汽车模型与 v0.7 SHA256 一致。灯具随新版跑道移动，共 86 个灯位。

验证：31 项状态/模拟测试、4 项 Sites 包装测试、生产构建及 Blender 压缩模型重新导入。覆盖全部十种出发路径的连续性、飞机与其他候班飞机的包围轮廓间距、客舱发光、刷新后组合稳定性。

当前模型与截图见 [机场夜景](renders/browser/v8-airport-night.png)、[起飞夜景](renders/browser/v8-air-moving-night.png)、[高铁出站](renders/browser/v8-rail-moving-night.png)。[场站验证](exports/transport-validation.json)、[浏览器验证](exports/browser-fleet-v8-qa.json)。以下版本章节保留各阶段的历史说明与截图。

## v0.6 昼夜光影

左上角的时间按钮打开光影控制。默认跟随北京时间，支持日出、早上、午后、傍晚、日落、夜晚六个预览，也可滑动到任意时刻，或用“两分钟一日”的漫游观看连续变化。再次点击漫游即可定格；手动时段与灯光开关会记住，重新载入时停止加速漫游。

- 阳光颜色、方向、阴影、环境光、海面和界面随时间平滑变化。深夜保留蓝色月光和可读的街区轮廓。
- 86 处路灯/场站照明，暖色住宅窗光、疏密不同的办公窗光、机场边灯与车站灯带；车辆增加随车移动的前后灯和路面光晕。
- 入夜逐渐亮灯，日出后逐渐熄灭；提供独立亮灯开关。泛光仅在足够暗时启用，避免日出和日落过曝。
- 城市光影时钟与真实行程、打卡日期完全独立。加速漫游不会推进任务或出发时间。
- 采用固定的游戏式日照节奏，不计算定位、季节或天文日出时间。
- [光影预览图集](renders/daylight-studies.html) · [灯具源文件](exports/city-lighting-rig.blend)。新增灯具是真实 Blender 网格，建筑窗光、车灯动画与光晕由网页渲染器控制。

## 统一尺度

建模单位为米。双向道路宽 6 m、每条车道 3 m；家庭车辆从实际顶点测得 **宽 1.938 m（含后视镜）× 长 4.381 m × 高 1.621 m**，成人高 **1.701 m**。住宅单栋正面宽 8.8 m。车厂已按这一尺度重新安排工位、设备和停车线，不再放大车辆填满街区。收集车宽约 2.5 m，同样可在一条车道内行驶。

尺寸规则见 [场景清单](modeling/scene-manifest.json)，顶点测量见 [比例验证](exports/scale-validation.json)。行人与车流已复用同一套米制资产；压缩后独立导入的实际尺寸见 `exports/mobility-validation.json`。

- 点击底部目录或地图中的街区，打开对应事务。
- 习惯打卡增加一个成长槽；家务完成减少对应杂物；两台车的事务各自独立。

## 行程出发动画 · v0.7

到了真实出发时间，飞机从停机位转向跑道，加速抬轮飞离海岛；随后新飞机进场降落，沿停机坪滑回候班。高铁从站台加速出站，在山体隧道中逐节隐入；新列车从另一侧隧道进站减速停靠。飞机一轮约 66 秒，高铁一轮约 39 秒。

点击场站的“看场站”可收起行程卡片，高铁会同时容纳两端山体。“预览出发”随时播放完整流程，预览不写入行程或打卡。真实班次开始时优先播放真实出发。

同一时刻同一交通方式的家庭行程共用一趟动画；时间接近的班次依次展示，前一轮补班完成后再出发。页面使用绝对时间计算进度，刷新会恢复该时刻的位置，旧行程不会重新出发；后台错过的动作不补播。昼夜预览和人流车流暂停不改变实际出发时间。

可动几何仍由 Blender 生成，分别位于 `transport_aircraft` 和 `transport_train` 节点。机场调整停机位及滑行引导线，为转向保留空间；两端隧道在内部裁切隐藏列车，避免穿出山背。七个原有分区、灯具与人车资产保持不变。

复现验证：`npm test`、`npm run build`、`npm run test:sites`、`npm run model:verify-transport`。实现见 `src/transport-state.mjs` 与 `src/CityTransport.mjs`，压缩模型检查见 `exports/transport-validation.json`。
